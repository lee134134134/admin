# 通用约束

## 语言规范（NON-NEGOTIABLE）

| 用途 | 语言 |
|------|------|
| 注释、文档 | **中文** |
| UI 文案、提示、表单标签 | **中文**（Element Plus 已设 zh-CN） |
| 变量、函数、类型、类名 | **英文** |
| git 提交信息 | **中文**（或团队既定格式） |
| CSS 类名 | **英文**（BEM） |

- 中文注释用半角冒号 + 空格：`// 代理到后端服务，按实际后端地址调整`
- **禁止**中英混杂的 UI 文案（如「加载 loading 中」）

## 占位与兜底（NON-NEGOTIABLE）

- 图标/图片资源未确定时：用 Element Plus 图标或占位 `div` + `<!-- TODO: 待替换 -->`，
  **禁止**引入临时外链图、占位图服务、base64 大图
- 明确标记替换点，便于后续检索 `TODO`
- 接口未就绪：保留占位接口 + 注释说明（见 `05-API规范`），不要伪造数据结构

## 可观测性与失败兜底

- 每个异步任务必须有**加载态**（`v-loading` / `el-skeleton` / 按钮 `loading`）
- 失败必须有兜底展示（空态、重试入口），**不允许**失败后白屏或静默
- 错误提示由 `request.ts` 拦截器统一负责，业务侧不再重复弹（见 `05-API规范`）
- 破坏性操作需二次确认

## 环境与配置

- 环境变量统一以 `VITE_` 开头，通过 `import.meta.env` 读取
- **禁止**在代码中硬编码后端地址、token、密钥等敏感信息
- 新增环境变量需同步 `.env.development` 并在 `01-项目概述` 登记

## 依赖管理（NON-NEGOTIABLE）

- 包管理只用 **pnpm**
- 新增第三方依赖前先确认：Element Plus / Pinia / Vue Router / Axios / Schedule-X 已覆盖的能力**不再重复引入**
- 优先复用 Element Plus 组件，**禁止**引入第二套 UI 库
- 大型依赖需在 `01-项目概述` 技术栈表登记

## 子模块与外部目录边界（NON-NEGOTIABLE）

| 目录 | 性质 | 约束 |
|------|------|------|
| `references/` | **git submodule**（外部工作流框架，dev 分支） | 禁止创建/修改本项目文件；引用其规范前先确认技术栈是否匹配 |
| `.agents/` | 规范唯一维护源 | 改动需同步更新 `README.md` 索引 |
| `.cursor/` `.claude/` `.opencode/` `.gemini/` `.trae/` | 软链 + OpenSpec 命令 | **禁止**直接编辑其中的 `rules/`、`skills/`（是软链，改这里=改 `.agents/`） |
| `openspec/` | SDD 工作区 | 由 `openspec` CLI 管理，不要手工挪动 `changes/archive` |
| `dist/` | 构建产物 | 禁止提交、禁止手改 |

## Git 约束

- **禁止**自行 `git commit` / `git push` / `git checkout --` / `git reset`，除非用户明确要求
- 当前分支 `main`；`references/workflows/git/commit-dev-branch.md` 要求 `dev` 分支，执行前必须与用户确认分支策略
- 不要动 `.husky/` 之外的 git 配置

## 兼容与安全

- 目标浏览器按 Vite 默认（现代浏览器），不需兼容 IE
- 不引入 `innerHTML` / `v-html` 渲染后端数据；确需时必须转义并说明理由
- 不在前端存储除 token 外的敏感凭据
