# 项目结构（NON-NEGOTIABLE）

## 目录结构

```
src/
├── api/                # 接口层
│   ├── request.ts      # axios 实例 + 拦截器 + httpGet/httpPost/httpPut/httpDelete
│   └── <业务域>.ts      # 按业务域划分: auth.ts / dashboard.ts / calendar.ts
├── assets/             # 静态资源与全局样式
│   └── main.css        # 全局 reset + 全局字体/底色（唯一的全局样式入口）
├── layouts/            # 布局组件
│   └── MainLayout.vue  # 深色侧边栏 #001529 + 顶栏 + 内容区
├── router/
│   └── index.ts        # 路由表 + 全局前置守卫（登录校验）
├── stores/             # Pinia store（setup store 风格），单文件单模块
│   └── user.ts         # useUserStore: token / 登录态
├── utils/              # 通用工具函数（无业务耦合）
│   ├── index.ts
│   ├── calendar.ts     # 日程领域计算
│   └── formatDateTime（如存在）
├── views/              # 页面组件，按路由一一对应
│   ├── LoginView.vue
│   ├── DashboardView.vue
│   ├── CalendarView.vue
│   └── <页面>/components/   # 页面私有子组件（不跨页面复用时放这里）
├── App.vue
├── main.ts             # 入口: 全量注册 Element Plus 图标 / Pinia / Router / zh-CN
└── vite-env.d.ts
```

## 结构约束

| 代码类型 | 必须放 | 禁止 |
|----------|--------|------|
| HTTP 接口函数 | `src/api/<业务域>.ts` | 组件内直接调 axios、新建 `src/http/`、`src/services/` |
| 类型定义（接口出入参） | 就近放在对应 `src/api/<业务域>.ts` | 新建 `src/types/`、`src/interfaces/` |
| 页面组件 | `src/views/XxxView.vue` | 放进 `src/components/`、嵌套子目录 |
| 跨页面复用组件 | `src/components/<组件名>/index.vue` | 散落在 views 各处 |
| 页面私有组件 | `src/views/<页面>/components/` | 提前抽到全局 |
| 全局状态 | `src/stores/<模块>.ts` | 新建 `src/state/`、组件内持有跨页状态 |
| 工具函数 | `src/utils/` | 写在组件里重复实现 |
| 常量 / 枚举 | 就近放在使用模块；跨模块才考虑 `src/constants/` | 魔法字面量散落 |
| 路由 | `src/router/index.ts` 集中注册 | 新建 `src/router/modules/` 散落（除非路由数显著增长） |
| 全局样式 | `src/assets/main.css` | 组件外写 `:global` 散弹式覆盖 |

## 硬性约束

- **禁止新建上述之外的顶层目录**。需要新目录时，先更新本文件与 `.agents/README.md`。
- 页面与路由**一一对应**：`views/XxxView.vue` ↔ `router/index.ts` 中一条 route。
- 组件级私有子组件放**同页面目录**下，不提前抽象为通用组件（YAGNI）。
- `references/` 是 **git submodule**（外部工作流框架），**禁止在其中创建或修改本项目文件**。
- `.agents/` 是规范唯一维护源，改动需同步更新对应 `README.md` 索引。
