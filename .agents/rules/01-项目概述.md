# 项目概述

## 项目定位

**AI Admin** —— AI 服务管理后台（外包项目），基于 Vue 3 + TypeScript + Vite 的**单页应用（SPA）**管理端，
面向 AI 服务的运营、监控与配置管理。

- 所属工作区：`/Users/lee/Documents/code/waibao/ai/`
- 兄弟项目：`ai-agent`（后端）、`ragAdmin`、`ros2`、`yijing`
- 后端：Go + Gin + GORM + SQLite，代码在 `ai-agent/apps/backend`

## 技术栈（强制，禁止引入替代方案）

| 领域 | 选型 | 说明 |
|------|------|------|
| 框架 | Vue 3.5 | Composition API + `<script setup lang="ts">`，**禁止 Options API** |
| 构建 | Vite 7 | 配置在 `vite.config.ts` |
| 语言 | TypeScript 5.8 | **strict 模式**（含 `noUnusedLocals` / `noUnusedParameters`），禁止 JavaScript |
| UI 框架 | Element Plus 2.x | **全量引入**（`main.ts` 已注册），国际化 zh-CN |
| 图标 | @element-plus/icons-vue | `main.ts` 已全量注册为全局组件 |
| 状态 | Pinia 3 | **setup store 风格**（`defineStore('x', () => {...})`） |
| 路由 | Vue Router 4 | history 模式 |
| HTTP | Axios | 统一封装在 `src/api/request.ts`，**禁止组件内直接调 axios** |
| 包管理 | pnpm | 锁文件 `pnpm-lock.yaml`，**禁止 npm / yarn** |
| 日程 | Schedule-X 4.x | 仅 `CalendarView` 使用，含 `temporal-polyfill` |

## 后端接口约定

| 项 | 约定 |
|----|------|
| base | 默认 `/api`；开发环境经 Vite proxy 转发 `http://localhost:8000`（见 `vite.config.ts`） |
| 覆盖 | `.env.development` 的 `VITE_API_BASE_URL` 可覆盖，留空则走代理 |
| 鉴权 | `Authorization: Bearer <token>`，token 存 localStorage（key: `token`），自动注入 |
| 401 | 拦截器统一清 token 并跳 `/login` |
| 其他错误 | 拦截器统一弹 `ElMessage.error`，业务代码**不处理错误** |
| 超时 | 15s |
| 响应 | 拦截器直接返回 `response.data`，即 `httpGet<T>` 拿到的就是 `T` |

## 环境与命令

| 命令 | 说明 |
|------|------|
| `pnpm dev` | 开发服务器 http://localhost:5173 |
| `pnpm type-check` | `vue-tsc --noEmit`，**改动后必跑** |
| `pnpm lint` | ESLint 检查 |
| `pnpm format:check` | Prettier 检查 |
| `pnpm build` | 类型检查 + 生产构建 |

> 后端 Go 模块下载需 `GOPROXY=https://goproxy.cn,direct`（官方代理超时）。
