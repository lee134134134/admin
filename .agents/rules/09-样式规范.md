# 样式规范

## 作用域（NON-NEGOTIABLE）

- 组件样式一律 `<style scoped>`，**禁止**无作用域的组件级样式
- 全局样式**只允许**在 `src/assets/main.css`（reset、全局字体、底色）
- 禁止散落 `:global()` 覆盖；确需全局覆盖 Element Plus 时，集中到 `main.css` 并加注释说明原因

## 命名（NON-NEGOTIABLE）

BEM：`block__element--modifier`

```css
.main-layout { }            /* block */
.main-layout__aside { }     /* element */
.main-layout__menu--flat { } /* modifier */
```

- 与 Vue scoped 的属性选择器兼容，不需额外前缀
- 动态状态类用 `is-*` / `has-*`：`.is-active`、`.has-border`
- **禁止**用 Element Plus 内部类名（如 `.el-button--primary`）做业务选择器——升级即碎，
  需要定制时用主题变量或业务类包裹

## Element Plus 主题（NON-NEGOTIABLE）

本项目**全量引入** Element Plus，主题定制通过 **CSS 变量覆盖**实现，不改源码、不引入第二套主题包。

```css
/* 集中在 assets/main.css，不要散落在组件里 */
:root {
  --el-color-primary: #1677ff;
  --el-border-radius-base: 4px;
}
```

常用变量：

| 变量 | 用途 |
|------|------|
| `--el-color-primary` | 主色 |
| `--el-text-color-primary / regular / secondary / placeholder` | 文本层级 |
| `--el-bg-color` / `--el-bg-color-overlay` | 背景 |
| `--el-border-color / light / lighter` | 边框 |
| `--el-fill-color-light / lighter` | 填充 |
| `--el-border-radius-base / small` | 圆角 |

> 完整清单见 Element Plus 官方「CSS 变量」文档，可用 Context7 MCP 查询当前版本。

## 颜色与设计 token（NON-NEGOTIABLE）

- **禁止硬编码任意色值**，优先用 Element Plus 变量
- 本项目**既有设计 token**（来自设计稿，允许直接使用，不要"纠正"为变量）：

| token | 值 | 归属 |
|-------|-----|------|
| 侧边栏底色 | `#001529` | `MainLayout` 深色侧边栏 |
| 内容区底色 | `#f5f7fa` | `main-layout__main` |
| 分隔线 | `#e4e7ed` | 顶栏底边框 |
| 主文本 | `#303133` | 顶栏用户区 |
| 侧边栏文本 | `rgba(255, 255, 255, 0.65)` | `el-menu` text-color |
| 侧边栏激活 | `#ffffff` | `el-menu` active-text-color |

- **新增页面的颜色优先复用上表或 Element Plus 变量**；确需新色值时在本文件登记再使用
- 分类/语义色（如日历分类色）写在**该组件的 `calendars` 配置**中并集中声明，不散落

## 布局约定

- 页面根节点撑满父容器；`MainLayout` 的 `el-main` 已提供内边距与底色
- 间距用 4/8 的倍数（4px、8px、12px、16px、24px），**禁止**随意 `13px` `17px`
- 尺寸优先用 Element Plus 尺寸变量或 `rem/%`；固定高度（如 header 60px）需有注释理由

## 响应式

- 默认按**桌面端管理后台**设计（最小可用宽 1280px）
- 侧边栏宽度 `220px` 固定；需要折叠交互时用 `el-aside` 的 collapse 能力，不要自造
- 涉及新增断点时，先与用户确认目标分辨率

## 样式检查清单

- [ ] `<style scoped>` 已加
- [ ] 类名符合 BEM
- [ ] 未硬编码新色值（或已在本文件登记）
- [ ] 未依赖 Element Plus 内部类名
- [ ] 间距为 4/8 倍数
