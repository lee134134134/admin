# 组件规范

## 书写形式（NON-NEGOTIABLE）

- 一律 `<script setup lang="ts">` + Composition API，**禁止 Options API**
- SFC 段落顺序固定：`<script setup>` → `<template>` → `<style scoped>`
- 组件文件名 PascalCase，页面组件以 `View` 结尾（`CalendarView.vue`），布局以 `Layout` 结尾

```vue
<script setup lang="ts">
import { computed } from 'vue'

interface Props {
  title: string
  items?: string[]
}

const props = withDefaults(defineProps<Props>(), { items: () => [] })
</script>

<template>
  <div class="stat-card">
    <span class="stat-card__title">{{ title }}</span>
  </div>
</template>

<style scoped>
.stat-card {
  /* ... */
}
</style>
```

## Props 与事件（NON-NEGOTIABLE）

- **必须用 `defineProps<{...}>` 或 `withDefaults(defineProps<...>, ...)` 显式声明类型**，禁止运行时对象声明 + 无类型
- Props 用 `PascalCase`；模板中用 kebab-case（`:max-count`）
- 事件用 `defineEmits<{...}>` 显式声明；事件名 `camelCase`，模板中 `kebab-case` 或 `update:xxx`
- **禁止**子组件直接修改 props；需要回传用 emit
- 单向数据流：父传子 props，子传父 emit，**禁止**用 store 中转本可 props/emit 解决的数据

## 组件层级归属（NON-NEGOTIABLE）

| 层级 | 判定 | 位置 |
|------|------|------|
| 页面组件 | 路由直接渲染，一页一个 | `src/views/XxxView.vue` |
| 页面私有组件 | 只被**一个**页面使用 | `src/views/<页面>/components/` |
| 通用组件 | 被 **两个及以上**页面使用 | `src/components/<组件名>/index.vue` |

> **不足两处复用时不要提前抽象**——先放页面私有，出现第二个使用方再上提。

## 布局组件

- 页面骨架放 `src/layouts/`（当前只有 `MainLayout.vue`）
- 顶栏标题**取自 `route.meta.title`**，禁止在布局里硬编码路由标题映射

## 拆分参考

- 单文件（`<template>` + `<script>` + `<style>` 合计）接近 **400 行**时考虑拆分
- 优先把「无业务的展示片段」下放为页面私有组件
- 拆不动的复杂逻辑抽成组合式函数（`useXxx`），放 `src/composables/`（**新建该目录前先更新 `03-项目结构`**）

## 样式

- 一律 `<style scoped>`，**禁止**无作用域的组件级样式
- 类名用 BEM：`block__element--modifier`（如 `main-layout__aside`）
- 动态 class 用对象/数组语法：`:class="{ 'is-active': active }"`
- 详见 `09-样式规范`

## 交互与文案

- 加载态、空态、错误兜底**必须给出**（Element Plus：`el-empty`、`v-loading`、`el-skeleton`）
- UI 文案用中文，语气与现有页面一致，禁止中英混杂或占位英文
- 破坏性操作（删除、登出）需二次确认（`ElMessageBox.confirm`）
